# Thank you to the authors

Thank you to Zhiqin Yang, Yonggang Zhang, Wei Xue, Dong Fang, Bo Han, and Yike
Guo for making the paper's assumptions, derivations, and experimental claims
available for independent examination.

The paper's explicit distinction between the conditional equivalence claim,
its failure modes, and provable alternatives made it possible to audit a
finite counterexample, exact algebra, a small preference pilot, and the
benchmark evidence boundary without conflating them. The repository preserves
the negative C1 result and the C6 missing-provenance blocker rather than
turning partial evidence into a broad claim.

This is an independent reproduction archive, not an authors' implementation or
endorsement. Please cite both the paper and this repository when using the
code or evidence; see [`CITATION.cff`](CITATION.cff).
